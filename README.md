# 🐠 Tienda Web de Venta de Peces Tropicales

Aplicación web desarrollada para la visualización y gestión de peces tropicales y accesorios para acuarios. El proyecto permite explorar productos mediante filtros dinámicos, categorías y búsquedas, ofreciendo una experiencia de usuario intuitiva y un diseño adaptable a distintos dispositivos.

## 🚀 Características Principales

✅ Catálogo de peces tropicales y accesorios.

✅ Sistema de filtros por categorías.

✅ Búsqueda dinámica de productos.

✅ Diseño responsive para dispositivos móviles y escritorio.

✅ Carga dinámica de información mediante archivos JSON.

✅ Interfaz moderna y amigable para el usuario.

## ⚙️ Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/TU-USUARIO/tienda-web-de-venta-de-peces-tropicales.git
```

2. Ingresar a la carpeta del proyecto.

3. Abrir el archivo `index.html` en cualquier navegador web.
